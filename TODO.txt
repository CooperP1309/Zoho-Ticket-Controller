(Heading) How Tickets are Decided

When out of testing phase, the system will automatically pick 
the top agent on the table. I need your help to provide feedback
on the algorithm. I.e. report if it made bad choices.

The algorithm determines which agent has the most relevant skills
to the ticket. This is reflected as the "SIMILARITY" score.

But before allocating the ticket to that person, it will check ticket 
counts and determine if that agent is overloaded. In which case, they'll 
be bumped down to the bottom of the list.

** DISCLAIMER ** 

How the system considers someone as "overloaded" is completely up for
discussion. This is just a prototype.
